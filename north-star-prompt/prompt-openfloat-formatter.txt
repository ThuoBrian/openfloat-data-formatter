# 🌟 Airtime Data Formatter

## North Star Prompt
Build a lightweight local application that automates the airtime disbursement workflow by transforming Excel exports from **Process Maker** into the required **OpenFloat SaaS template**.  
The tool must ensure accuracy, reduce manual effort, and provide a simple interface for staff to generate ready‑to‑upload files or push data directly via API.

---

## 🚀 Project Overview
The Airtime Data Formatter (ADF) eliminates repetitive manual steps in the airtime workflow:
1. Download data from **Process Maker** (Excel format).  
2. Automatically transform and validate the data.  
3. Output a clean, OpenFloat‑ready file.  
4. (Optional) Push directly to **OpenFloat SaaS** via API.  

---

## 🎯 Goals
- Automate manual formatting tasks.  
- Reduce human error in airtime processing.  
- Save time and scale for bulk uploads.  
- Provide reliability, clear error handling, and maintainability.  

---

## 🛠 Tech Stack
- **Backend:** Python (Pandas, OpenPyXL), FastAPI  
- **Frontend:** React.js (optional UI)  
- **Deployment:** Docker, Azure Functions / AWS Lambda (serverless option)  
- **Integration:** OpenFloat API (if available), lightweight database for logs
